# InfoStation 全自动财经情报站 — 方案与计划

> 定位：美股 + 加密货币，中英双语。每个交易日两期：盘后复盘（16:9 长视频 + X 推文串，含盘后财报）和盘前速览（只出 X 推文串 + 图卡）。
> 上传由人工完成；系统产出到「上传包」为止。

## 0. 已确定的决策

| 项 | 决策 |
| --- | --- |
| 语言 | 中文、英文各一版（各自原生写稿，不是机翻） |
| 市场 | 美股（主）+ 加密货币（固定板块） |
| 大脑 | `agy -p --json-schema`（Antigravity CLI，模型 `gemini-4-argon-medium`），Python 只把数据包交给它，拿回结构化 JSON |
| 渲染 | Remotion（React 模板 → 无头 Chrome 逐帧 → FFmpeg），默认 30fps，可配 60 |
| 产物 | 16:9 长视频 ×2（zh/en）、X 推文串 ×2 + 数据卡片图、缩略图、字幕、YouTube 标题/简介/章节 |
| 运行 | `uv run infostation run`（cron / systemd 定时），也可在 agy / Claude Code 里用一句话驱动 |

## 1. 对 Gemini 方案的修正（实测 + 已知变化）

| 原方案说法 | 实际情况 | 本项目处理 |
| --- | --- | --- |
| Reddit 加 `.json` 免 Key 抓取 | **实测 403**。Reddit 2023 后封锁匿名 JSON，新 API App 需要审批 | 默认用 **ApeWisdom**（聚合 Reddit/4chan 提及量，免 Key，实测 200）；Reddit OAuth 作为可选增强 |
| Finnhub 免费档能拿 K 线 | 2024 起 `stock/candle` 已转付费；免费档仅报价/新闻/日历/内部人等 | K 线统一走 yfinance；Finnhub 只做新闻与日历（可选 Key） |
| yfinance 稳定可批量 | 2025 起频繁 `YFRateLimitError` | 批量 `download` 一次拉全宇宙；本地 DuckDB 缓存；失败降级 Stooq |
| 每只股票拉完整期权链算 P/C | 请求量巨大且易被限流 | 只对最终 3 只重点股拉最近 2 个到期日 |
| 新闻正文可直接喂给 LLM 并引用 | 版权：只能摘要 + 注明来源，不能念原文 | Prompt 强制「转述 + 来源」，正文只取前 N 字做背景 |
| 从 YouTube 拉财报会音频切原声 | 他人频道转载触发 Content ID；且耗时 | 列入第二阶段，仅用公司 IR 官方 webcast，片段 ≤15 秒 |
| Agent 写稿即可 | **LLM 编造数字是财经号的头号死因** | 数字只能来自数据包；写完后程序化「数字核对」，不通过就打回重写 |

## 2. 方案里没考虑到的风险（重要）

1. **YouTube 盈利政策**：2025-07 起 YPP 把「批量生产、重复性」内容列为 *inauthentic content*，不予盈利。全自动无脸频道要避免模板化：
   - 每期由 LLM 选「今日主线」，结构随新闻变化，不是固定填空；
   - 保留人工审核环节（系统产出 `review.md` 检查清单）；
   - 固定的人设与观点栏目（例如「情绪背离雷达」），形成辨识度。
2. **AI 内容披露**：合成人声读数据一般不需要勾选「Altered or synthetic content」；但若之后用 H3 生成逼真人物/场景，必须勾选。上传包里会给出提示。
3. **投资建议合规**：每期片尾 + 简介固定免责声明；Prompt 禁止「买入/卖出/目标价」类指令性措辞。
4. **素材版权**：不使用新闻图片；画面全部由程序画图 + 本地 ComfyUI 生成；BGM 用你自己放入的免版税音乐。
5. **时区与交易日历**：一律按纽约时间（交易所时间）调度和判断时段，定时器直接写 `America/New_York`，夏令时自动处理；对外内容里的时间以美东为准，中文附洛杉矶 / 北京时间，英文附洛杉矶时间（`timefmt.py`）。节假日、半日市、周末自动跳过。
6. **数据商条款**：Yahoo 数据不得再分发原始数据，视频里展示派生图表属常见做法但有灰度；SEC 数据为公有领域，优先引用。
7. **Ticker 误识别**：散户讨论里 `$A`、`IT`、`ALL`、`YOLO` 等会被误判为股票，需要黑名单 + 最小市值过滤。
8. **爬虫腐烂**：免费源每月必坏一两次 → 每个源独立降级、`infostation doctor` 一键体检，运行报告写明哪些源失败。
9. **agy 调用本身**：单次 1–2 分钟、有约 15k token 固定开销 → 每次运行合并为 4 次批量调用（编辑、中文稿、英文稿、推文串），中英文并行；超时重试；全部失败时用模板稿兜底，不让管线中断。实测 gemini-3.8-flash 写长稿会返回空结果，已改用 argon。
10. **数据口径一致性**：同一视频里不能出现两个不同的 BTC 涨跌幅（股市按收盘、加密按 24h 滚动），大盘卡片用指数而不是 ETF 价格。
11. **新闻噪音**：Google News 按代码搜索会混入“报价页/价格预测”SEO 页面，需要过滤。

## 3. 视频技术选型

- **Remotion**（采用）：本身就是“无头 Chrome 按帧号逐帧截图 + FFmpeg 合成”，帧时钟确定，不会掉帧；数据驱动的
  图表动画（K 线逐根画出、数字滚动、柱状图生长）用 React/SVG 写，模板一次写好每天复用。
- **Playwright 自己截帧**（不采用）：等于重造 Remotion，还要自己处理动画时钟同步。
- **Three.js**：需要 3D 片头/粒子背景时用 `@remotion/three` 嵌入；WebGPU 在无头模式下还不稳定，先用 WebGL。
- **Blender**：画质最好但慢，只用于一次性制作片头/转场素材，不进每日管线。
- **agy 的角色**：开发期写模板；运行期只输出结构化分镜与台词，渲染由固定模板确定性完成。

实测（Ryzen 9950X，concurrency 16）：约 20 渲染帧/秒，7 分钟 30fps 视频约 10 分钟/语言。

## 4. 架构

```
cron/systemd ──► infostation run --session auto
                     │
  ① collect   行情(yfinance/Stooq) · 加密(Binance/CoinGecko/恐惧贪婪) · SEC(8-K/Form 4)
              · 社交热度(ApeWisdom/Reddit可选) · 新闻RSS · 财报/宏观日历 ──► DuckDB 历史库
  ② screen    漏斗：宇宙 ~150 只 → 异动/热度打分 Top 20 → 补新闻/SEC → 候选
  ③ analyze   agy #1：情绪打分 + 多空要点 + 选出今日 3 条主线（结构化 JSON）
  ④ datapack  把所有「可引用事实」整理成带编号的数据包（数字已格式化）
  ⑤ write     agy #2/#3：中/英分镜脚本（并行）→ 数字核对 → 不过则带错误清单重写一次
              agy #4：中/英 X 推文串（字数按 X 加权规则校验）
  ⑥ visuals   matplotlib 图表 + PIL 场景卡（深色主题、中英字体）；可选 ComfyUI 缩略图背景
  ⑦ voice     edge-tts（免费，句级时间戳）→ 字幕；接口可换本地 GPT-SoVITS/CosyVoice
  ⑧ render    ffmpeg：场景图 + 轻微推镜 + 配音 + BGM 侧链压低 + 字幕 + 响度标准化（NVENC）
  ⑨ package   上传包：视频、缩略图、SRT、标题/简介/章节/标签、推文串 + 配图、review.md
```

运行目录 `runs/2026-10-17_recap/` 保存每一步的中间产物；每步可单独重跑（`infostation run --from write`）。

## 5. 视频结构（长视频，约 5–8 分钟）

1. 开场：日期 + 今日 3 个钩子
2. 大盘看板：SPY/QQQ/DIA/IWM、VIX、10Y、美元、黄金、原油、BTC
3. 板块热力：11 个行业 ETF 涨跌
4. 异动榜：涨跌幅 + 成交量倍数
5. 主线 ×3：K 线 + 关键数据卡 + 新闻要点 + 散户情绪仪表 + 内部人/8-K
6. 加密板块：BTC/ETH/SOL、资金费率、恐惧贪婪指数
7. 前瞻：未来几日财报与宏观事件
8. 结尾 + 免责声明

## 6. 里程碑

- **M1（本次交付）**：①–⑨ 全链路跑通，产出中英双语视频 + 推文串 + 上传包；定时脚本；agy/Claude Code 驱动说明。
- **M2**：历史库满 30 天后启用「情绪分位数 / 提及量 z-score」纵向对比；周末周报。
- **M3**：财报电话会（官方 webcast → 本地 faster-whisper → 高管问答原声切片）。
- **M4**：Remotion 动效模板替换静态场景卡；H3 生成片头；Shorts 竖屏版。
